# おうちの電気 3D

家の3Dモデルで、分電盤・漏電・アース・感電のしくみを観察する日本語の体験教材です。リビング、キッチン、洗面室の回路を、電流の粒とブレーカーの動きで比較できます。

**[教材を開く](https://koji432.github.io/Energy_3D1014/)**

## 6つの場面

| 場面 | 観察すること |
| --- | --- |
| いつもの電気 | 分電盤で各回路に分かれ、家電を通って電源へ戻る |
| 家全体で使いすぎ | 各回路20 A未満でも合計37 Aが契約30 Aを超え、アンペアブレーカーが家全体を遮断 |
| 一つの回路で使いすぎ | 契約40 Aの家でキッチンだけ26 A。配線用遮断器がその回路を遮断 |
| ショートが起きたら | 家電を迂回する経路に大電流が流れ、配線用遮断器が遮断する例 |
| 漏電とアース線 | ケース→アース線→接地極→大地→電源側の接地。行きと戻りの差を漏電遮断器が検知 |
| アースがないと？ | 接触前は差が0でもケースは危険。人が触れて経路ができると、人体に電流が流れてから遮断 |

## 操作

- 左側の場面を選ぶと最初から再生します。スマートフォンでは上部の場面一覧を横にスクロールします。
- **家全体／分電盤／アース・人体**で視点を切り替えます。ドラッグで回転、ホイール・ピンチで拡大縮小、右ドラッグで平行移動できます。
- **一時停止・再生・最初から・0.5／1／2倍速・再生バー**で瞬間を観察できます。バーを戻せば遮断前に戻ります。
- 右側の**ブレーカー**を押すと、教材内で手動の入／切を比較できます。操作時は時間を最初に戻します。
- **条件を変えて試す**で契約容量、各回路の使用電流、故障、アース線、人体の接触を変更できます。変更すると最初から再生します。
- **Aa**で3Dラベルを隠せます。3D画面にフォーカスすると、矢印キーで回転、＋／−キーで拡大縮小できます。
- OSの「視差効果を減らす」設定では自動再生・カメラの滑らかな移動・粒の自動移動を抑えます。バー操作で各場面は観察できます。

## モデルの範囲と注意

家と家具はThree.jsで作成した、この教材独自の3Dデータです。実在住宅のCADデータではありません。画面構成と操作は従来の発電教材に合わせ、説明・比較機能を加えています。

- 単相2線式100 V、分岐3回路、各20 A、漏電遮断器の定格感度30 mAという簡略モデルです。単相3線式100／200 Vやスマートメーターによる契約容量制限など、すべての住宅方式を再現していません。
- 家庭の電気は交流です。黄色・青色の粒は、交流のある瞬間の電流経路を示します。電子が一方向に動き続ける図ではなく、配線色も教材用です。
- 12秒のバーは物語の進行です。故障や使いすぎの変化を位置4、人体の接触を位置5.5、検知の3目盛り後に遮断として見せています。**実際の遮断時間・過電流の動作特性ではありません。**
- ショートの150 A、漏電の50 mA、人体の5／50 mAは比較用の例です。実際の抵抗・電圧分布・事故電流は計算していません。**30 mAは安全な人体電流の上限ではありません。**
- アースと漏電遮断器の併用でも感電を完全には防げません。アースがあっても人体電流が0になるとは限らず、遮断前や感度未満でも危険があります。
- アースなし・接触なしで漏れ電流0となるのは、他に大地への経路がない理想化した例です。絶縁故障したケースは危険な電圧になり得ます。
- 大地の経路は見える位置に緑線で模式表示しています。漏電電流は大地で消えず、電源側の接地へ戻ります。住宅の分電盤で戻り線とアース線を接続していません。
- 役割を比較するため、漏電遮断器の過電流保護は省略しています。ショート・分岐過負荷は分岐側が先に遮断する例で、実際は上位遮断器も動作し得ます。遮断の協調や時間特性を計算したものではありません。
- 故障の原因を残したまま教材内で再生すると再び遮断します。実物で故障や接触を再現しないでください。工事・復旧手順書ではありません。

## 実行・編集

配信用ファイルを同梱しています。`index.html`を直接開いてもオフラインで動作し、外部CDN・APIキーは不要です。GitHub Pagesでは`main`のルートを配信元にします。

```sh
npm ci
npm test
npm run build
npm start
```

`http://127.0.0.1:4173`で確認できます。ソース変更後は`npm run build`で実行用の`app.bundle.js`を更新します。

- `simulation.js`：電流・遮断状態の決定と説明文。時間を指定して前後に移動しても同じ状態を再現します。
- `scene.js`：家・家具・分電盤・人体・配線の3Dモデル、カメラ、電流表示。
- `app.js`：場面選択、ブレーカー、再生、電流計、条件変更。
- `tests/simulation.test.js`：過負荷、漏電、感電、手動遮断、電流差、時間の巻き戻しを検証。

Three.js 0.180.0とOrbitControlsを同梱しています。MITライセンスは`vendor/THREE-LICENSE.txt`を参照してください。
