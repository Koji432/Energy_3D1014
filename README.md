# 火力発電所から家まで 3D

**[アプリを開く](https://koji432.github.io/Energy_3D1014/)**

火力発電所 → 送電線 → 変電所 → 配電線 → 家の分電盤を、一つの3D空間で観察するアプリです。電気の流れを追うカメラと、発電所・変電所・家の名称で、それぞれのつながりを示します。画面は名称とアニメーションの操作だけで構成し、説明文・電圧や電流の数値・光についての注記は表示しません。

## 発電所から家まで

通常のツアーは22秒です。最初の4秒でボイラー・蒸気・タービン・発電機の動きを示し、その後は電気の流れにフォーカスします。初期状態ではカメラが自動追従します。

- 光の太さ・明るさを段階的に変えて、降圧を表現します。粒の速さや個数で電流量を表しているわけではありません。
- 家には壁と屋根があり、電気が届くと窓が強く点灯し、窓の周囲と地面にも暖色の光が広がります。
- **家の注釈ボタン**または**「家の中へ」**を押すと、家に視点が移り、外装を外して分電盤のスイッチ操作に切り替わります。

タービンと発電機は内部が見えるモデルです。送電・変電・配電設備は、外観と接続経路を中心に示し、内部機構は簡略化しています。

## 家の分電盤

参考画像の配置に合わせ、左の赤いアンペアブレーカー、中央の灰色の漏電遮断器、右の部屋ごとの配線用遮断器を並べています。遮断器の外装とレバーだけを表示し、内部の接点・コイル・検知環は表示しません。

- **アンペアブレーカー**：本体・レバーまたは名称ボタンを押すと、家全体の電源を入／切します。
- **漏電遮断器**：本体・レバーまたは名称ボタンで入／切します。黄色いボタンまたは「漏電テスト」を押すと、検知ランプが点滅した後に漏電遮断器が切れ、家全体が消灯します。遮断器を再び入れるまで消灯を維持します。
- **配線用遮断器**：本体・レバーまたは各部屋の名称を押すと、その部屋だけが点灯／消灯します。主幹を切って再び入れても、各部屋のスイッチ位置を保ちます。
- **リセット**：漏電テストの状態を解除し、すべてのスイッチを入れます。
- **電気の流れに戻る**：分電盤を開く直前の再生位置と再生／停止状態に戻り、全景を表示します。分電盤の操作状態は次に開くまで保ちます。

分電盤の下の3つの照明と、背後にある実際の部屋の照明・電化製品を連動させています。漏電テストは漏電遮断器のテスト回路を模式化したもので、部屋のスイッチを切った状態でも作動します。アンペアブレーカーまたは漏電遮断器が切れている場合にはテストできません。検知の過程を観察できるよう、テスト開始から遮断までを1.2秒にしています。実機の動作時間ではありません。

送配電の光は、入力側に到達した後で出力側へ進みます。変電所の入口と出口、配電線と柱上変圧器への引き込みは別々の到達区間とし、光の粒と光る配線に同じ弧長座標を使います。家の点灯は引き込み線と家の回路・戻り経路の表示が完了してから始まります。

## 操作

- **スタート／最初から、一時停止／再開**：アニメーションを操作します。
- **倍速**：0.5・1・2倍に切り替えます。
- **再生バー**：好きな瞬間へ移動し、その位置で停止します。
- **追従**：電気の流れに合わせてカメラを動かします。
- **全景に戻る**：発電所から家までを見渡す表示に戻ります。
- **停止して最初に戻す**：再生を停止し、最初の状態に戻します。
- **ドラッグ／ピンチ・ホイール**：視点の回転／拡大縮小。手動で視点を操作すると自動追従を解除します。

## モデルの範囲

- 電圧・電流・動作時間は学習用の模式表示です。ツアーの時間は、実際の発電所の起動時間や送電速度ではありません。
- 光の太さ・明るさは**電圧の違い**を示す演出で、電力・電流の減少や実際の発光を表しません。粒は供給経路を示し、交流の電子が発電所から家へ一方向に進み続けることを表していません。
- 今回の操作画面は遮断範囲と漏電検知を示します。契約電流超過・過負荷・短絡の自動検出や実機の保護協調は計算していません。実際のアンペアブレーカーは契約電流の制限、配線用遮断器は分岐配線の過電流保護を担います。
- 漏電遮断器は漏電検出に焦点を当て、主幹の過電流保護機能は省略しています。実際には過電流保護を兼ねる製品もあります。アースと漏電遮断器は互いの代わりになるものではありません。
- アンペアブレーカーを備えた構成を採用しています。スマートメーターで契約電流を制限する住宅などでは、盤内にアンペアブレーカーがない場合もあります。
- 三相送電から単相2線100 Vの住宅への接続を簡略化しています。実際の住宅には単相3線100／200 Vの方式もあります。系統の多数の分岐、計量、損失、実機寸法・保護協調の計算は再現していません。

## 実行・編集

`index.html`を直接開いてもオフラインで動作します。外部CDN・APIキーは不要です。GitHub Pagesでは`main`のルートを配信します。

```sh
npm ci
npm test
npm run build
npm start
```

`http://127.0.0.1:4173`で確認できます。ソース変更後は`npm run build`で`app.bundle.js`を更新してください。

| ファイル | 内容 |
| --- | --- |
| `simulation.js` | 発電から点灯までの到達順序、手動スイッチと漏電テストの状態 |
| `flow-path.js` | 光る配線と粒の共通座標・到達範囲 |
| `board-lesson.js` | 分電盤の外装、クリックできるレバー、部屋の点灯 |
| `scene.js` | 発電所・送配電設備、光の経路、カメラ |
| `home-model.js` | 住宅・家具・分電盤の形状 |
| `geometry.js` | 3D形状を組み立てる共通処理 |
| `app.js` | 再生・分電盤の操作・戻る操作・視点の操作 |

Three.js 0.180.0とOrbitControlsを同梱しています。MITライセンスは`vendor/THREE-LICENSE.txt`を参照してください。
