# 火力発電所から家まで 3D

**[アプリを開く](https://koji432.github.io/Energy_3D1014/)**

火力発電所から送電線、変電所、配電線、家の分電盤までを、一つの3D空間で見渡すアプリです。説明文・見出し・設備名のラベルは表示せず、アニメーションと操作ボタンだけで構成しています。

## 観察できる流れ

1. ボイラーで水を加熱し、蒸気を送る。
2. 蒸気でタービンと発電機の軸が回る。
3. 発電所の変圧器から鉄塔の送電線へ光が進む。
4. 変電所を経て、電柱の配電線・柱上変圧器へ進む。
5. 引込線から家の分電盤へ入り、各部屋の回路と照明に届く。

タービンと発電機は内部が見える断面モデルです。送電・変電・配電設備は、外観と接続経路を中心に表現し、内部機構は省略しています。家は屋根を外したモデルで、分電盤と室内配線が見えます。

## 操作

- **スタート／最初から**：最初から再生します。最後まで届くと、通電した状態で粒・炎・回転が動き続けます。
- **一時停止／再開**：動きを止めて観察できます。
- **0.5／1／2倍速**：再生速度を変えます。
- **照準のアイコン**：電気の流れに合わせてカメラが発電所、送電線、変電所、配電線、分電盤、家を順に追います。初期状態では全景のまま再生します。
- **四隅のアイコン**：全景に戻ります。
- **戻す矢印**：再生を停止し、未通電の最初の状態に戻ります。
- **再生バー**：好きな瞬間へ移動し、その位置で停止します。巻き戻すと設備の状態も戻ります。
- **設備をクリック／タップ**：その設備を拡大します。分電盤も個別に拡大できます。
- **ドラッグ／ピンチ・ホイール**：回転／拡大縮小。右ドラッグで平行移動できます。手動操作するとカメラの自動追従は解除されます。
- **キーボード**：3D画面にフォーカスし、矢印で回転、＋／−で拡大縮小、Homeで全景に戻ります。

画面の幅に合わせて全景の向きを変え、スマートフォンでも全体が収まります。自動再生は行いません。「視差効果を減らす」設定では視点切替の補間を省き、物語が最後まで進むと粒・炎・回転も停止します。

## モデルの範囲

- 36秒の再生バーは、理解する順番を示す演出です。実際の発電所の起動時間、送電速度、電力系統の応答時間ではありません。
- 黄金色の粒は、電力が届く経路を模式的に示します。交流の電子が発電所から家へ一方向に移動し続けることを表していません。家の青い線は戻り側の経路です。
- 発電所内の青は水、橙色は蒸気の流れです。復水器の冷却水は蒸気・給水回路と別の配管で表現しています。
- 三相の送電線、変圧器の高圧側・低圧側、住宅への単相2線の引込を簡略化しています。変圧器内部、系統の分岐、保護・開閉設備、計量設備、損失や数値計算は省略しています。
- 住宅の分電盤は電源を室内の3回路に分ける姿を示します。以前の漏電・過負荷・感電の場面選択と設定画面は、今回の目的変更に合わせて置き換えています。
- 全設備は、このアプリ用に作成した3Dモデルです。実在設備の寸法や設計図を再現したものではありません。

## 実行・編集

配信用のファイルを同梱しています。`index.html`を直接開いてもオフラインで動作し、外部CDN・APIキーは不要です。GitHub Pagesでは`main`のルートを配信元にします。

```sh
npm ci
npm test
npm run build
npm start
```

`http://127.0.0.1:4173`で確認できます。ソース変更後は`npm run build`で実行用の`app.bundle.js`を更新してください。

| ファイル | 内容 |
| --- | --- |
| `simulation.js` | 発電から点灯までの進行と再生状態 |
| `scene.js` | 発電所・送配電設備、経路、粒、カメラ |
| `home-model.js` | 住宅・家具・分電盤の形状 |
| `geometry.js` | 3D形状を組み立てる共通処理 |
| `app.js` | 再生・停止・速度・追従・巻き戻しの操作 |
| `tests/simulation.test.js` | 供給順序、停止、倍速、巻き戻し、再生完了の検証 |

Three.js 0.180.0とOrbitControlsを同梱しています。MITライセンスは`vendor/THREE-LICENSE.txt`を参照してください。
